# CineTicket
Historias de usuario:

1- Como cliente quiero iniciar sesión en la web para ingresar a la web de CineTicket
   Criterios de aceptación
   - Deben validarse correctamente los datos del usuario
   - Debe dirigir correctamente a la página de inicio una vez iniciada la sesión correctamente

2- Como usuario quiero ver la cartelera del día para saber qué películas están siendo transmitidas
  Criterios de aceptación
  - El usuario debe ser capaz de ingresar a la web y visualizar la cartelera de películas del cine
  - La cartelera debe estar actualizada
